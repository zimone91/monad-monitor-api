# Code of conduct

This applies to issues and every other space of this repository.

- Be respectful. Criticize data, code and documentation, not people.
- Stay on topic: this API, its data and its documentation.
- No harassment, personal attacks, spam or promotion.

The maintainer may edit, lock or remove content that breaks these rules, and may block accounts that repeat it.

To report a problem privately, write to <privacy@zim.one>.
